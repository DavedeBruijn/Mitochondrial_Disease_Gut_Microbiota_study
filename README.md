# Mitochondrial Disease Microbiome

## Description
The codes used for the data analysis of the Mitochondrial Disease Microbiota study related to "Gut microbiota alterations in individuals with mitochondrial disease caused by the m.3243A >G mutation" 

## Installation
All the used Rpackages are mentioned in the script and could be installed with install.packges()
