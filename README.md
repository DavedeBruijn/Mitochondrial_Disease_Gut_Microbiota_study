# Mitochondrial Disease Microbiome

## Description
The codes used for the data analysis of the Mitochondrial Disease Microbiota study related to "The gut microbiota of patients with mitochondrial disease caused by the m.3243A>G mutation is altered compared to healthy controls and patients with type 1 diabetes" 

## Installation
All the used Rpackages are mentioned in the script and could be installed with install.packges()
